# Dados dos Concorrentes — Coleta Semanal

> Preencha este arquivo antes de domingo à noite. A routine de segunda 7h vai ler estes dados para a análise comparativa.
>
> **Não precisa preencher tudo.** Quanto mais dados, melhor a análise — mas mesmo só 2-3 perfis com 2-3 posts cada já gera insights úteis.

---

## Como preencher

Para cada perfil, copie informações dos 2-3 últimos posts:

- **Tipo**: Reel, Foto, Carrossel
- **Data**: data e horário aproximado (ex: "qui 19h")
- **Tema**: do que é o post (ex: "tutorial sombra esfumada")
- **Likes**: número aproximado
- **Comentários**: número aproximado
- **Legenda**: cole a legenda ou um resumo (3-4 linhas)
